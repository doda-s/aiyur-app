# Aiyur

Aiyur é um aplicativo Android desenvolvido com Flutter, voltado para o gerenciamento de listas de filmes, séries e animes. A proposta do projeto é oferecer uma experiência simples e organizada para catalogar produções assistidas, em andamento ou planejadas, funcionando como uma solução pessoal de acompanhamento de mídia. O projeto é inspirado em plataformas como MyAnimeList e AniList, porém com foco mais abrangente no universo audiovisual como um todo.

---

## Objetivo

O objetivo do Aiyur é fornecer uma plataforma intuitiva e funcional para:

- Gerenciar listas de filmes, séries e animes.
- Acompanhar o progresso de consumo.
- Avaliar produções de forma organizada.
- Centralizar informações e preferências do usuário.

## Como executar o projeto

Antes de iniciar, certifique-se de ter o Flutter instalado corretamente na sua máquina.

```bash
# Verificar a instalação do Flutter
flutter --version

# Clonar este repositório
git clone https://github.com/SeuUsuario/Aiyur.git

# Acessar o diretório do projeto
cd Aiyur

# Instalar dependências
flutter pub get

# Executar o aplicativo em modo debug
flutter run
```
